\# Перестановка строк матрицы



\## Назначение проекта

Программа предназначена для обработки вещественной матрицы. Она находит максимальный и минимальный элементы матрицы и меняет местами строки, в которых расположены эти элементы.



\## Требования к окружению

\- Windows 7/10/11 или Linux

\- Python 3.x



\## Запуск программы

1\. Установить Python 3.x.

2\. Открыть терминал в каталоге проекта.

3\. Запустить программу командой:

&#x20;  python src/main.py
