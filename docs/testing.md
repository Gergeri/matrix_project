\# План тестирования



\## Цель тестирования



Проверить правильность поиска минимального и максимального элементов матрицы и перестановки соответствующих строк.



\## Основной тест



Входные данные:



\[\[1, 2], \[3, 4]]



Ожидаемый результат:



\[\[3, 4], \[1, 2]]



\## Автоматическое тестирование



Для автоматической проверки используется модуль unittest языка Python.



Запуск тестов:



python -m unittest tests/test\_main.py



Тестирование также автоматически выполняется с помощью GitHub Actions при отправке изменений в репозиторий.
