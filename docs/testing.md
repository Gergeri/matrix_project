# План и результаты тестирования

## 1. Общая информация

Проект: matrix_project.
Предметная область: перестановка строк матрицы.
Лабораторная работа №4.
Вариант №12.
Уровень 3 (высокий).

Цель тестирования — проверить правильность ввода, обработки и вывода матрицы, взаимодействие модулей и обработку исключительных ситуаций.

Инструмент: unittest (Python).
Методы: покрытие операторов, решений, условий и комбинаторное покрытие условий.
Целевое покрытие: не менее 80%.

## 2. План тестирования

Тестированию подлежат четыре модуля:

- input_module.py — ввод и проверка данных.
- processing_module.py — поиск минимального и максимального элементов, перестановка строк.
- output_module.py — вывод матрицы.
- main.py — управление выполнением программы.

Порядок проверки:

1. Запуск модульных тестов.
2. Проверка условий и ветвлений.
3. Интеграционное тестирование.
4. Проверка исключительных ситуаций.
5. Измерение покрытия кода.
6. Анализ полученных результатов.
