

\# Тестирование интеграции программных модулей



\## 1. Цель тестирования



Проверить корректность взаимодействия модулей ввода, обработки и вывода матрицы в единой программе.



\## 2. Средства тестирования



Язык программирования: Python.



Библиотека тестирования: unittest.



Среда выполнения: Git Bash, Windows.



Автоматическая проверка: GitHub Actions.



\## 3. Тестовые сценарии



| № | Проверка | Ожидаемый результат | Фактический результат |

|---|---|---|---|

| 1 | Перестановка строк матрицы 2×2 | Строки меняются местами | Успешно |

| 2 | Минимальный и максимальный элементы в одной строке | Матрица не изменяется | Успешно |

| 3 | Матрица с отрицательными числами | Корректная перестановка строк | Успешно |

| 4 | Запуск программы через главный модуль | Все модули взаимодействуют | Успешно |

| 5 | Автоматическое тестирование GitHub Actions | Успешное выполнение workflow | Успешно |



\## 4. Результаты тестирования



Тестирование проводилось командой:



python -m unittest discover -s tests -v



Результат:



Ran 3 tests in 0.000s



OK



Все три автоматических теста завершились успешно.



\## 5. Проверка интеграции



Программа запускалась командой:



python -m src.main



Входная матрица:



1 2

3 4



Результат обработки:



3.0 4.0

1.0 2.0



Результат соответствует ожидаемому.

После отправки изменений в репозиторий GitHub автоматически запустил workflow CI.



Коммит: 1b56741.



Статус выполнения: успешно.



Время выполнения: 11 секунд.



\## 7. Вывод



Интеграция модулей выполнена успешно.



Функции обработки матрицы работают корректно на проверенных тестовых примерах.



Программа запускается через главный модуль, а автоматические тесты успешно выполняются локально и через GitHub Actions.
