

\# Интеграция программных модулей



\## 1. Общая информация



Проект: matrix\_project.



Назначение: обработка вещественной матрицы с поиском минимального и максимального элементов и перестановкой строк, в которых они находятся.



Вариант: 12.



Уровень: 3 (высокий).



Способ выполнения: сохранение предметной области проекта из ЛР №1 и ЛР №2.



Стратегия интеграции: Т-образная.



Способ взаимодействия: прямой вызов функций Python.



\## 2. Структура модулей



\- src/input\_module.py — ввод размеров и элементов матрицы.

\- src/processing\_module.py — поиск минимального и максимального элементов и перестановка строк.

\- src/output\_module.py — вывод матрицы.

\- src/main.py — объединение модулей и управление выполнением программы.



\## 3. Архитектура взаимодействия



Главный модуль main.py вызывает функции остальных модулей.



Схема потока данных:



Пользователь

&#x20;   |

&#x20;   v

input\_module.py

&#x20;   |

&#x20;   v

main.py

&#x20;   |

&#x20;   v

processing\_module.py

&#x20;   |

&#x20;   v

output\_module.py

&#x20;   |

&#x20;   v

Результат



Модуль ввода формирует матрицу и передаёт её главному модулю.



Главный модуль передаёт матрицу в модуль обработки, который определяет номера строк с минимальным и максимальным элементами и переставляет эти строки.



Результат передаётся модулю вывода для отображения пользователю.



\## 4. Стратегия интеграции



Используется Т-образная интеграция, предусмотренная вариантом 12.



Сначала проверяется полный путь обработки данных от ввода до вывода. Затем отдельно тестируются функции обработки и граничные случаи.



Такой подход позволяет проверить взаимодействие всех основных компонентов программы.



\## 5. Интерфейсы модулей



input\_matrix() — не принимает аргументов, возвращает двумерный список чисел float.



find\_min\_max(matrix) — принимает матрицу, возвращает индексы строк с минимальным и максимальным элементами.



swap\_rows(matrix, max\_row, min\_row) — принимает матрицу и индексы строк, переставляет строки на месте.



print\_matrix(matrix) — принимает матрицу и выводит её элементы.



\## 6. Формат обмена данными



Передача данных осуществляется через прямые вызовы функций Python.



Матрица представлена двумерным списком чисел.



Пример входных данных:



\[\[1.0, 2.0], \[3.0, 4.0]]



Пример результата:



\[\[3.0, 4.0], \[1.0, 2.0]]



REST API, SOAP и gRPC не используются, поскольку вариантом предусмотрен прямой вызов функций.



\## 7. Сопоставление объектов данных



| Источник | Данные | Получатель | Представление |

|---|---|---|---|

| input\_module | matrix | main | list\[list\[float]] |

| main | matrix | processing\_module | list\[list\[float]] |

| processing\_module | min\_row, max\_row | main | int, int |

| main | matrix | output\_module | list\[list\[float]] |



Введённые пользователем строки преобразуются в числа float.



Номера строк представлены целыми числами int.



\## 8. Тестирование



Интеграционные проверки выполняются с помощью unittest.



Команда запуска:



python -m unittest discover -s tests -v



Программа запускается командой:



python -m src.main



Автоматическое тестирование выполняется через GitHub Actions.



Результаты тестирования документируются в docs/integration\_test.md.
