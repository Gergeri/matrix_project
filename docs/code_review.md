

\# Инспекция кода интеграции



\## 1. Цель



Проверить качество исходного кода интегрированной программы, соблюдение стандартов Python и корректность взаимодействия модулей.



\## 2. Проверяемые файлы



\- src/main.py

\- src/input\_module.py

\- src/processing\_module.py

\- src/output\_module.py

\- tests/test\_main.py



\## 3. Критерии проверки



1\. Разделение программы на независимые модули.

2\. Понятные названия функций и переменных.

3\. Правильность импортов.

4\. Корректность передачи данных.

5\. Обработка некорректного ввода.

6\. Наличие автоматических тестов.

7\. Соответствие рекомендациям PEP 8.



\## 4. Структура программы



Программа состоит из модулей ввода, обработки и вывода.



Главный модуль main.py объединяет компоненты с помощью прямых вызовов функций Python.



Каждый модуль выполняет отдельную задачу, что упрощает сопровождение программы и тестирование.



\## 5. Автоматическая проверка



Для проверки стандартов кодирования используется flake8.



Команда:



python -m flake8 src tests



Результаты проверки фиксируются после выполнения команды.



\## 6. Проверка тестирования



Команда:



python -m unittest discover -s tests -v



На первоначальном этапе три теста завершились успешно.



Дополнительная проверка покрытия кода выполняется с помощью coverage.



\## 7. Вывод



Программа разделена на функциональные модули, интеграция реализована через вызовы функций.



Окончательные результаты инспекции будут определены после запуска линтера и проверки покрытия кода.
