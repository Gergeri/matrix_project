Названия тестов отражают проверяемые сценарии.

Для проверки ожидаемых результатов используются
assertEqual, assertIn и assertRaises.

Предусмотрены проверки:
- корректной перестановки строк;
- отрицательных чисел;
- одинаковых элементов;
- некорректных размеров матрицы;
- нечисловых значений;
- пустой матрицы;
- ошибок обработки;
- ошибок импорта;
- повторного выполнения программы.

Выявлено частичное дублирование сценариев
перестановки строк и одинаковых элементов
в основных и регрессионных тестах.

Дублирование сохранено для отдельного запуска
регрессионного набора.
