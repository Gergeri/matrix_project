\# Архитектура проекта



Проект представляет собой консольное приложение на языке Python для обработки вещественной матрицы.



\## Основные модули



\- input\_matrix() — ввод матрицы и проверка корректности данных.

\- find\_min\_max(matrix) — поиск минимального и максимального элементов и определение строк, в которых они расположены.

\- swap\_rows(matrix, max\_row, min\_row) — перестановка строк.

\- print\_matrix(matrix) — вывод матрицы.

\- main() — управление последовательностью выполнения программы.



Исходный код программы расположен в каталоге src/, тесты — в tests/, документация — в docs/.
