\# Российские аналоги Git



В России существуют отечественные платформы для хранения исходного кода и совместной разработки программных проектов. Большинство из них основаны на Git и поддерживают привычный процесс работы с репозиториями.



\## 1. GitFlic



GitFlic — российская DevOps-платформа для хранения кода и совместной разработки. Позиционируется как альтернатива GitLab и доступна в облачном и локальном вариантах.



Основные возможности:

\- хранение Git-репозиториев;

\- совместная разработка;

\- управление исходным кодом;

\- использование в облачном и локальном вариантах.



Преимущества:

\- российская разработка;

\- поддержка Git;

\- возможность локального развёртывания.



Ограничения:

\- менее распространена по сравнению с зарубежными платформами.



Номер в Едином реестре российского ПО: №15861.



\## 2. GitFlame



GitFlame — сервис хранения репозиториев с версионным контролем исходного кода, предназначенный для разработчиков и DevOps-инженеров. Построен на системе контроля версий Git.



Основные возможности:

\- хранение исходного кода;

\- работа с Git-репозиториями;

\- контроль версий;

\- совместная работа над проектами.



Преимущества:

\- использование стандарта Git;

\- ориентированность на разработчиков и DevOps-инженеров.



Ограничения:

\- меньшая распространённость по сравнению с крупными зарубежными сервисами.



Номер в Едином реестре российского ПО: №21590.



\## 3. Deckhouse Code



Deckhouse Code — решение для непрерывной разработки и управления жизненным циклом программного обеспечения.



Основные возможности:

\- хранение исходного кода;

\- управление разработкой;

\- поддержка CI/CD;

\- управление жизненным циклом программного обеспечения.



Преимущества:

\- наличие инструментов CI/CD;

\- возможность использования в процессе непрерывной разработки.



Ограничения:

\- для небольших учебных проектов часть возможностей платформы может быть избыточной.



Номер в Едином реестре российского ПО: №27871.



\## Вывод



Российские платформы поддерживают работу с Git и предоставляют инструменты для хранения исходного кода и совместной разработки. GitFlic подходит как отечественная альтернатива GitLab, GitFlame ориентирован на работу с Git-репозиториями, а Deckhouse Code дополнительно предоставляет инструменты CI/CD.
